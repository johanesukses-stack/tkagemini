Konfigurasi AI Gemini & Pengiriman Jawaban Siswa (MI Husnayain Sleman)

1. Koneksi Generator Soal AI (Gemini API)

Mode Hibrida

Agar variasi soal dihasilkan secara dinamis tanpa batas oleh AI (bukan hanya lokal), masukkan Gemini API Key Anda (gratis dari aistudio.google.com) ATAU gunakan URL Web App Google Apps Script sebagai proxy AI.

2. Endpoint Google Apps Script (Terima Jawaban Siswa & Proxy AI)

Masukkan URL Web App Google Apps Script (`https://script.google.com/macros/s/.../exec`) milik Anda. Setiap kali siswa MI Husnayain Sleman menyelesaikan ujian, nama, kelas, nilai, dan rincian jawaban siswa akan otomatis masuk ke Google Spreadsheet Guru.

Panduan Akses Ujian Siswa (GitHub Pages & Google Apps Script) — MI Husnayain Sleman

Bagaimana Agar Siswa Hanya Melihat Halaman Ujian Online & Jawaban Terkirim ke Guru?

Aplikasi TKA GURU | MI Husnayain Sleman telah dilengkapi fitur Auto-Lock Mode Siswa. Jika URL dibuka dengan akhiran ?mode=siswa&pkg=ID_PAKET, maka Dashboard Guru, Editor, dan Kunci Jawaban otomatis disembunyikan. Siswa hanya melihat Form Identitas Siswa + Soal Ujian, dan saat klik Kumpulkan, nilai otomatis dikirim ke Google Sheet Anda!

LANGKAH 1: Pasang Kode Penerima Nilai & Proxy AI di Google Spreadsheet (Apps Script)

  1. Buka Google Sheets baru, beri nama "Rekap Nilai TKA MI Husnayain Sleman".
  2. Klik menu Ekstensi (Extensions) → Apps Script, hapus kode yang ada di Code.gs, lalu tempel kode di bawah ini:
  3. Klik Terapkan (Deploy) → Deployment Baru (New Deployment) → Pilih jenis Aplikasi Web (Web App).
  4. Pada bagian Execute as pilih Me (Saya), dan pada Who has access pilih Anyone (Siapa saja), lalu klik Deploy.
  5. Salin URL Web App (`https://script.google.com/macros/s/.../exec`) lalu tempelkan ke menu Pengaturan (Ikon Roda Gigi) di aplikasi ini.
/**
 * BACKEND GOOGLE APPS SCRIPT — TKA GURU | MI HUSNAYAIN SLEMAN
 * Fungsi:
 * 1. Menerima & menyimpan jawaban serta nilai ujian siswa otomatis ke Google Sheet
 * 2. Menyimpan paket soal di Cloud Sheet agar bisa diakses siswa dari link pendek
 * 3. (Opsional) Proxy Gemini API jika Anda menyimpan GEMINI_API_KEY di Script Properties
 */

function doPost(e) {
  try {
    var payload = JSON.parse(e.postData.contents);
    var ss = SpreadsheetApp.getActiveSpreadsheet();

    // 1. JIKA SISWA MENGUMPULKAN JAWABAN UJIAN
    if (payload.action === 'submit_exam') {
      var sheet = ss.getSheetByName('Nilai_Siswa');
      if (!sheet) {
        sheet = ss.insertSheet('Nilai_Siswa');
        sheet.appendRow([
          'Timestamp', 'Nama Siswa', 'Kelas', 'No Absen',
          'Mata Pelajaran', 'Judul Paket', 'Nilai Akhir',
          'Benar', 'Salah', 'Kosong', 'Detail Jawaban', 'Rekomendasi'
        ]);
        sheet.getRange(1, 1, 1, 12).setFontWeight('bold').setBackground('#dbeafe');
      }
      sheet.appendRow([
        new Date(),
        payload.studentName,
        payload.studentClass,
        payload.studentAbsen,
        payload.subject,
        payload.packageTitle,
        payload.score,
        payload.correct,
        payload.wrong,
        payload.empty,
        JSON.stringify(payload.answersSummary),
        payload.recommendation
      ]);
      return ContentService.createTextOutput(JSON.stringify({ status: 'ok', message: 'Nilai tersimpan di Sheet!' }))
        .setMimeType(ContentService.MimeType.JSON);
    }

    // 2. JIKA GURU MENYIMPAN PAKET SOAL KE CLOUD SHEET
    if (payload.action === 'save_package') {
      var pkgSheet = ss.getSheetByName('Bank_Paket');
      if (!pkgSheet) {
        pkgSheet = ss.insertSheet('Bank_Paket');
        pkgSheet.appendRow(['Package_ID', 'Subject', 'Title', 'Updated_At', 'JSON_Data']);
      }
      var data = pkgSheet.getDataRange().getValues();
      var foundRow = -1;
      for (var i = 1; i < data.length; i++) {
        if (data[i][0] === payload.packageData.id) { foundRow = i + 1; break; }
      }
      if (foundRow > 0) {
        pkgSheet.getRange(foundRow, 2, 1, 4).setValues([[payload.packageData.subject, payload.packageData.title, new Date(), JSON.stringify(payload.packageData)]]);
      } else {
        pkgSheet.appendRow([payload.packageData.id, payload.packageData.subject, payload.packageData.title, new Date(), JSON.stringify(payload.packageData)]);
      }
      return ContentService.createTextOutput(JSON.stringify({ status: 'ok' })).setMimeType(ContentService.MimeType.JSON);
    }
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ status: 'error', message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  var action = e.parameter.action;
  var ss = SpreadsheetApp.getActiveSpreadsheet();

  // Ambil Paket Soal berdasarkan ID untuk Siswa
  if (action === 'get_package' && e.parameter.id) {
    var pkgSheet = ss.getSheetByName('Bank_Paket');
    if (pkgSheet) {
      var data = pkgSheet.getDataRange().getValues();
      for (var i = 1; i < data.length; i++) {
        if (data[i][0] === e.parameter.id) {
          return ContentService.createTextOutput(data[i][4]).setMimeType(ContentService.MimeType.JSON);
        }
      }
    }
    return ContentService.createTextOutput(JSON.stringify({ error: 'Paket tidak ditemukan' })).setMimeType(ContentService.MimeType.JSON);
  }

  // Ambil Daftar Nilai Siswa untuk Dashboard Guru
  if (action === 'get_scores') {
    var sheet = ss.getSheetByName('Nilai_Siswa');
    if (!sheet) return ContentService.createTextOutput('[]').setMimeType(ContentService.MimeType.JSON);
    var rows = sheet.getDataRange().getValues();
    rows.shift();
    return ContentService.createTextOutput(JSON.stringify(rows)).setMimeType(ContentService.MimeType.JSON);
  }

  return ContentService.createTextOutput(JSON.stringify({ status: 'TKA GURU MI Husnayain Sleman Active' })).setMimeType(ContentService.MimeType.JSON);
}

LANGKAH 2: Cara Upload ke GitHub Pages Agar Bisa Diakses Siswa dari Rumah/Lab

  1. Setelah Anda membuat paket soal AI dan memasukkan URL Web App Google Apps Script di aplikasi ini, klik tombol "Simpan .HTML" di pojok kanan atas. File yang terunduh sudah otomatis menyimpan seluruh paket soal & URL Webhook Anda di dalamnya!
  2. Ubah nama file `TKA_GURU.html` menjadi index.html, lalu unggah (*push*) ke repositori GitHub Pages Anda (misal: https://username.github.io/tka-husnayain/).
  3. Untuk membagikan ke siswa, klik tombol "Akses Siswa & Rekap" pada navbar atas, lalu salin Tautan Khusus Ujian Siswa (contoh: https://username.github.io/tka-husnayain/?mode=siswa&pkg=PKG-MATH-...).
  4. Saat siswa membuka tautan tersebut, mereka hanya bisa melihat halaman ujian (tanpa tombol kembali ke dashboard guru dan tanpa kunci jawaban).
